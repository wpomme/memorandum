## Bitwise operaion: ビット演算
### 文字列と二進数、1６進数の変換
```bash
## 文字列から16進数に変換する
echo -n "a" | xxd -p
# > 61

## 16進数から該当の文字列を表示する
echo "0x61" | xxd -r
# > a

## ASCII以外の文字についても同様
echo "あ" | nkf -guess # > UTF-8

## 全角ひらがなは３バイト文字
echo -n "あ" | xxd -p
# > e38182

##
echo "0xe38182" | xxd -r
# > あ
```

### 二進数と16進数、十進数の変換
```bash
## 二進数から16進数へ変換する
printf '%X' $((2#01100001))
# > 61

## 16進数から二進数へ変換する
echo "obase=2; ibase=16; 61" | bc
# > 1100001

## 十進数から二進数へと変換する
echo "obase=2; 75" | bc
# > 1001011

## 二進数から十進数へと変換する
echo "ibase=2; 1001011" | bc
# > 75
```

## バーナム暗号の検証
    - ref: https://ja.wikipedia.org/wiki/%E3%83%90%E3%83%BC%E3%83%8A%E3%83%A0%E6%9A%97%E5%8F%B7
    - 排他的論理和を２回取ると0になることを利用する
        - 暗号化: P ^ K = C
        - 復号化: C ^ K = (P ^ K) ^ K = P ^ (K ^ K) = P
```bash
# 通信文P
printf '%X' $((2#01001011))
# > 4B

# 鍵K
printf '%X' $((2#00011101))
# > 1D

# 暗号文C
echo $((2#01001011 ^ 2#00011101))
echo $((0x4B ^ 0x1D))
# > 86


echo $((2#01010110 ^ 2#00011101))
# > 75
echo "obase=2; 75" | bc
# > 1001011
```

## package.json: 

### バージョン指定について
- 数字のみ: 指定したバージョンと正確に一致するバージョンがインストールされる

- キャレット(^): メジャーバージョン以外の更新は可能とする
    - ^1.2.3: 1.2.3以上、2.0.0未満までのバージョン更新を可能とする

- チルダ(~): マイナーバージョンの更新を可能とする
    - ~1.2.3: 1.2.3以上、1.3.0未満までのバージョン更新を可能とする

- 大なり(>): 指定したバージョン以上なら更新可能とする

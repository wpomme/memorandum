- WikipediaのGNU Core Utilitiesの分類に従う
    - https://en.wikipedia.org/wiki/GNU_Core_Utilities
        - Core Utilitiesのものはcoreへ、それ以外(gh, jq, brewなど)はthird-partyへ
        - file, process, search, textの四つ
